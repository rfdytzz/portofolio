# Portfolio — rfkdytp

Personal portfolio website built to showcase my projects, skills, and journey as a developer.

## About

This portfolio represents my journey as a developer who enjoys turning ideas into simple, functional, and thoughtful interfaces.

The website focuses on a clean, modern, and interactive experience while keeping the interface lightweight and easy to navigate.

## Tech Stack

- Vue.js
- Vite
- Tailwind CSS
- Lenis
- Vue Router
- JavaScript

## Features

- Responsive design
- Modern dark interface
- Smooth scrolling with Lenis
- Custom animated cursor
- Interactive spotlight effect
- Animated hero typography
- Project showcase
- About section
- Contact section
- GitHub integration
